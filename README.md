# ReceiptJournal ダウンロード

## ツールについて

ReceiptJournal は、領収書・請求書のテキストから仕訳CSVを作成する変換ツールです。

## ダウンロード方法

ダウンロードは、このリポジトリの Releases から行ってください。

- Releases: https://github.com/amanogawa8721/receipt-journal-dist/releases
- 最新の Release に添付されている `ReceiptJournal-win-locked.zip` をダウンロードしてください。

## パスワードについて

zip ファイルのパスワードは、購入者向け案内をご確認ください。

## 動作環境

- Windows

## 注意事項

- このリポジトリは配布用のダウンロード置き場です。ソースコードは置いていません。
